🐤 dark-canary

Mirror production traffic to a shadow deployment and diff the responses.

One binary sits in front of both, answers the client from the primary, and fires a copy at the shadow — a dead end whose latency and failures can never reach the user. The product is the diff engine: structural comparison plus declarative noise suppression for timestamps, IDs, ordering and float precision, so the only thing left in the report is a real behaviour change.

Run
make build
./bin/dark-canary -rules noise.example.yaml \
  -primary http://127.0.0.1:9001 -shadow http://127.0.0.1:9002

or: helm install dc charts/dark-canary · dashboard and report on :8099
